Sibani High School Management System

A desktop management system built in C# (Windows Forms) to digitise day-to-day school administration for Sibani High School, replacing manual/paper-based processes with a single, structured system.

About

This project was built to give school staff a faster, more reliable way to manage day-to-day administration. Records that used to live across paper files, spreadsheets, and memory now live in one system with proper structure, validation, and reporting.

Features
 Student record management (add, edit, search student profiles)
 Attendance tracking
 Marks / academic performance recording
 Fees / payments tracking
 Staff and access management (role-based access, e.g. admin vs teacher)
 Reports and exports (e.g. PDF/Excel reports for attendance, marks, or fees)
 Dashboard with key school stats at a glance
Tech Stack
Language: C#
UI Framework: Windows Forms
Database: SQL Server / SQL
IDE: Visual Studio
